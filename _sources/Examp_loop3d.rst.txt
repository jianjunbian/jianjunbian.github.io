3D dislocation loop
==========================

.. |loop3d|  image:: img/loop3d.jpg
   :width: 80%
   :align: bottom 

|loop3d|

*( a ) a single crystal BCC Fe sample. ( b ) Triangulation mesh grid of a surface in 3D space, and pink lines are the profile of the plane. ( c ) A 3D dislocaiton loop was constructed based on geomertrical surface in ( b ).*

--------

As shown in abvoe figure, by using a mesh grid data file, we could construct a 3D dislocation loop in crystal. The steps are given as follows:  

**Step 1:**

  Use the tool in the subdirectory :doc:`tools/Bcc <Tools>` to creat an BCC single crystal sample by running the following command in Terminal. This will produce an ASCII text file of the atomic structure in current directory: ``bcc_reg.lmp``. Use the tool in the subdirectory :doc:`tools/3DLoop <Tools>` to to create the mesh of a 3D surface: ``3dLoop.mesh``

.. code-block:: Shell 
   :linenos:

   #bash
   Bcc 100 100 100 -x 1 -1 0 -y 1 1 -2 -z 1 1 1 Fe

   #bash
   3DLoop -c 0 0 0 25 6 13
   

**Step 2:**

  Open terminal, run the following command:

.. code-block:: Shell 
   :linenos:

   CryDisGen para_file bcc_reg.lmp

--------

.. admonition::  Parameter file 

   Content of the :doc:`para_file <ParaFile>`:

.. code-block:: CryDisGen
   :linenos:

   #lines starting with '#' are comments 
   #crystal region definition
   Region
   -x      1 -1  0      # lattice orientation along x-axis
   -y      1  1 -2      # lattice orientation along y-axis
   -z      1  1  1      # lattice orientation along z-axis
   -lat    2.866        # lattice constant
   -pbc    1  1  1      # boundary condition flags along x/y/z-axes: '1' for periodic, '0' for non-periodic

   nHelix 1
   Helix
   -bvh   1  1  1
   -bsh   1/2
   -f     3dLoop.mesh
